Harjoitus 2a: Luokat ja oliot

Tässä harjoituksessa harjoittelin olio-ohjelmoinnin perusteita luomalla kolme luokkaa: Car, Rectangle ja Student.

Car luokassa harjoittelin jäsenmuuttujien ja setter metodien käyttöä sekä olion luomista pinomuistiin.

Rectangle luokassa harjoittelin pinta-alan ja ympärysmitan laskemista sekä olion luomista kekomuistiin ja muistin vapauttamista.

Student luokassa harjoittelin getter ja setter metodeja sekä smart pointerin käyttöä.

Lähteet: https://peatutor.com/cplus/index.php#olioista
Harjoituksessa hyödynnetyt materiaalin osiot:

luokka, getter ja setter, private/public/protected, olio pino, keko ja smart pointer
